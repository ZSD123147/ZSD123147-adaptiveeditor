## 一、插件介绍

**自适应编辑器**：Z-BlogPHP 后台写作与管理插件。界面与后台框架完全解耦，桌面与手机同一套自适应代码，不引入任何第三方依赖。

- **写文章**：标题、富文本正文、插入超链接、图片上传、图片灯箱预览、分类、状态下拉（含公开、草稿、审核状态）、置顶（含首页、全局、分类）、标签绑定与新建、发布时间、发布 / 提交审核。
- **文章管理**：按分类 / 状态筛选、标题与正文搜索、分页、单篇编辑、单篇与批量删除。
- **设置**：正文区高度、列表每页条数、粘贴模式、发布后去向、图片本地化、原生后台入口。

## 二、安装与启用

1. 把 `adaptiveeditor` 整个目录放到 `zb_users/plugin/` 下（通过后台「应用中心」安装的会自动就位）。
2. 进入后台 → **插件管理** → 找到「自适应编辑器」→ 点击 **启用**。
3. 启用后，「文章管理」「插件管理」页的二级菜单里会出现「自适应编辑器」快捷入口；如需在后台左侧菜单也显示入口，到 **设置 → 原生后台入口** 打开。

## 三、使用要点与常见问题

**粘贴与格式**

- 「图文模式」下只保留内核白名单内的格式（段落、加粗、斜体、下划线、标题、列表、表格、代码、图片）；引用、删除线、上下标、内联事件，以及来源带进来的超链接与跟踪参数会被清掉——编辑区看到的就是前台最终的样子。
- 随时可用 `Ctrl/⌘ + Shift + V` 临时按纯文本粘贴；「纯文本模式」则一律按纯文本处理，每行成为一个段落。
- **Q：为什么「引用」「删除线」等格式粘贴后消失了？** 清洗规则与内核保存时一致，只保留可安全落库的格式。需要保留时改用「纯文本模式」或手动排版。

**图片上传**

- 支持 `jpg / jpeg / png / gif / bmp / webp`，大小上限跟随站点「上传文件大小」设置，需要 `UploadPst` 权限。
- 开启「图片本地化」后，编辑时图片只是预览，**保存文章时**才真正上传转存（站外图片一并下载回本站）。
- **Q：粘贴的图片没上传成功？** 先检查是否有 `UploadPst` 权限、体积是否超限；若开启了「图片本地化」，图片在保存文章时才上传，编辑阶段只是预览。

**批量删除**

- 需同时满足 `PostBat` 权限 + 站点开启「启用文章批量删除」+ 单次 ≤ 200 篇，条件不满足时页面会给出说明；单篇删除只需 `ArticleDel` 权限。

**标签**

- 最多 20 个（与内核一致）；逗号分隔可一次添加多个，可一键绑定常用标签。

- **Q：设置项能填多大？** 保存时按规则自动夹紧（正文区高度 200–2000 px、列表每页条数 5–100 篇），越界输入不会写入；停用或卸载插件都不影响已保存的设置。
